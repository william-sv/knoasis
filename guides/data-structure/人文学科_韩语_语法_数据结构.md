> 本规范描述韩语语法知识数据的字段结构与受控词表，供数据整理与第三方接入参考。

## 2. 必填字段

| 字段 | 类型 | 作用 |
|------|------|------|
| headword | string | 条目主词（语法型 / 语尾 / 助词），作为检索键与展示标题 |
| id | string(自编码) | 稳定主键，**必填**；格式 `ko[a-z0-9]{12}`（总长 14 位，12 位后缀随机打乱、无顺序规律，无连字符），脚本随机分配，全局唯一，与 headword 无派生关系（见 §10） |
| category | string | 分类节点名（实际取值见 §10 `category` 受控词表，如 复合表达 / 连接语尾 / 助词 / 终结语尾），用于分组与侧栏导航 |
| tags | string[] | 标签数组，支持检索与跨节点归并；承载**分类标签**（如 连接语尾(연결어미)）、**功能标签**（如 疑问(의문)）、**语用标签**（如 敬语(높임)）三类，可组合；格式与受控词表见 §10 |
| summary | string | 摘要文本，用于列表预览与搜索命中 |
| content | object | 内容容器，必须包含 paragraphs |
| content.paragraphs.explanation | string(markdown) | 形态规则讲解（缀合公式、不规则处理、리/르 边界等），渲染为 Markdown / KaTeX；**只讲形态怎么变，不含义项/语用**（义项由 §9 senses 独占） |

## 3. 可选字段

| 字段 | 类型 | 作用 |
|------|------|------|
| type | string | 语法点词性（품사），取值见 §10 受控词表 |
| sort | number | 同分类内排序权重（章节序），缺省按 headword 排序 |
| level | string | 难度等级，仅 `I` / `II`（对应 TOPIK I / TOPIK II）；空串 = 未分级，见 §10 |
| speechLevel | string | 句式层级/阶称（해라체/해요체/하십시오체/하오체/반말 + 격식체/비격식체），见 §10 受控词表；与 `tags` 敬语轴互补不重复 |
| aliases | string[] | 异体写法（如 `-(으)ㅂ시다`、`-아요`/`-어요` 同语尾两变体），提升检索命中 |
| sources | SourceItem[] | 权威出处溯源，见 §6 |
| content.connections | ConnectionItem[] | 连接要求（결합 제약 / 선행 형식）；每项含 `realizations`（形态实现，见 §5.1） |
| content.lists.examples | ExampleItem[] | 例句列表 |
| content.similar | SimilarItem[] | 近义语法辨析 |
| content.common_errors | ErrorItem[] | 易错点 / 使用制限（否定·时态·主语限制等） |
| content.senses | SenseItem[] | 多义项（义项独占，见 §9）；部分语法点有独立义项（如 `-던` 回想/持续） |
| related | string[] | 关联引用，两类：① 内部引用 = 本数据集条目 `id`（`ko[a-z0-9]{12}`）；② 外部参照 = `ext:<概念>`（如 `ext:jondaenmal` / `ext:정말`），不强制匹配，仅作展示 |

## 4. examples 条目（ExampleItem）

| 字段 | 必填 | 类型 | 作用 |
|------|------|------|------|
| ko | 是 | string | 韩语源例句（谚文） |
| zh | 否 | string | 中文译文 |
| audio | 否 | string | 音频占位（空串 `""`，暂未采集音频素材） |
| note | 否 | string | 针对该句的注释 |

## 5. connections 条目（ConnectionItem）

| 字段 | 必填 | 类型 | 作用 |
|------|------|------|------|
| attachesTo | 是 | enum | 可连接的词类，见 §10 受控词表（移除 `verb-and-adjective`，已按动词/形容词拆分） |
| requiredForm | 是 | string | 前述成分所需形态（活用形 / 缀合式），如 `어간 + 아/어` |
| example | 否 | string | 该接法的具体实例 |
| meaning | 否 | string | 该接法对应的语义 / 语用 |
| tense | 否 | enum | 时态标注：`past` / `future`（仅相关语尾） |
| constraints | 否 | object | 接法约束/制限（仅个别连接含，如 `-아/어/여서`）：结构含 `sequential`（时序，如 `{sameSubject:true}` 表前后句主语须一致）、`causal`（因果，如 `{excludeMood:["imperative","propositive"]}` 表后句排除祈使/共动）、`incompatibleWith`（互斥词尾数组，如 `["았/었"]` 表不可与过去时制词尾连用） |
| realizations | 否 | RealizationItem[] | **形态实现**：代表词干 → 真实形态；词干类型必须匹配本行 `attachesTo` 词类 |

### 5.1 realizations 条目（RealizationItem）

| 字段 | 必填 | 类型 | 作用 |
|------|------|------|------|
| stem | 是 | string | 代表词干（如 `가다` / `먹다` / `하다` / `크다` / `예쁘다` / `춥다`） |
| ko | 是 | string | 该词干下的真实形态（如 `가요` / `먹어요` / `해요` / `커요` / `예뻐요` / `추워요`） |
| note | 否 | string | 形态规则说明（元音和谐 / ㅡ脱落 / ㄹ不规则·ㅂ不规则·ㅎ不规则 等）；不规则类型另见 §10 `irregularity` 受控词表 |

> 设计原则：`realizations` 与 `connections` 正交且单源——前者纵向展开"给定词干后的真实形态"，后者横向记录"接在什么词类、接续公式"。`realizations` 的词干类型受本行 `attachesTo` 约束（动词行的 `realizations` 不得含形容词词干），从根本上消除历史错行。简单语尾（如 `-지만`）列 1–3 个代表词干即可，不强制穷举、不复制 `connections`。

## 10. 语言特有字段 / 受控词表

- `type` 受控词表（**值用中文，韩文作括注**）：`助词`(조사) / `语尾`(어미) / `辅助用言`(보조용언) / `冠形词`(관형사) / `副词`(부사) / `接续词`(접속사) / `依存名词`(의존명사)。允许为空串：部分条目可留空，由 `category` + 形态判定词性，不强制填写。
- `category` 受控词表（实际取值，**值用中文**）：`复合表达` / `连接语尾` / `助词` / `终结语尾` / `定语语尾` / `先语末语尾` / `否定副词` / `名词型转性语尾`。分类按语尾功能（连接/终结/定语/先语末/名词型转性）与词类（助词/副词/复合表达）划分。
- `speechLevel` 受控词表（句式层级/阶称，**值用中文，韩文作括注**）：`平叙体`(해라체) / `准敬语体`(해요체) / `敬语体`(하십시오체) / `河湖体`(하오체) / `非敬语`(반말)；横轴另含 `正式`(격식체) / `非正式`(비격식체)。与 `tags` 敬语轴（敬语/非敬语/正式/非正式）互补不重复——`speechLevel` 讲「句式阶称」，`tags` 敬语轴讲「礼貌维度」，二者维度不同、不互斥。
- `attachesTo` 受控词表：`noun`(명사) / `verb`(동사) / `adjective`(형용사)。（原 `verb-and-adjective` 自早期版本起移除——"动词与形容词共享活用"条目拆分为 verb、adjective 两个独立 ConnectionItem。）
- `irregularity` 受控词表（可选，挂在 `connections[].realizations[]` 上，标注形态实现偏离规则直拼的不规则/缩约类型，利于学习者）：`ㅡ脱落`(예쁘다→예뻐) / `ㅂ不规则` / `ㅎ不规则` / `ㄷ不规则` / `ㅅ不规则` / `르不规则`(모르다→몰라서) / `하不规则`(하다→해) / `모음축약`(보다→봐서)。取值**全用韩语标签，禁缩写码**（如 `b-irr`）。标注了 `irregularity` 的 realization，其 `ko` 必须偏离 `stem` 直拼（见 §12 自洽校验）。
- `level`：**仅** `I` / `II`（对应 TOPIK I / TOPIK II；I 含 1–2 级，II 含 3–6 级）。空串表示未分级。
- `tags` 格式：**「中文(韩文)」** 或 **「中文、韩文」** 两种均可，例如 `["准敬语(해요체)"]` 或 `["准敬语、해요체"]`。建议全局统一一种写法。
- `id` 自编码规则：固定前缀 `ko` + 12 位**随机打乱**的小写字母或数字（`[a-z0-9]`，无字母/数字顺序规律，无连字符），总长度严格 14 位，如 `koa1b2c3d4e5f6`、`ko7x9q2m3z8n1v4`。由脚本随机生成，**全局唯一**，不与 headword 绑定（避免可推测的顺序编码）；同批数据不得重复（唯一性校验见 §12）。
- `tags` 功能标签受控词表（建议，可组合，格式「中文(韩文)」）：
  - **句式功能**：陈述(서술) / 疑问(의문) / 命令(명령) / 共动·建议(청유) / 感叹(감탄) / 确认(확인) / 肯定(긍정) / 否定(부정)
  - **时制**：过去(과거) / 现在(현재) / 将来(미래) / 进行(진행) / 完成(완료) / 经历(경험)
  - **法·语态**：推测(추측) / 意愿(의지) / 打算(계획) / 可能(가능) / 能力(능력) / 被动(피동) / 使动(사동) / 状态变化(상태변화)
  - **连接关系**：原因(이유) / 目的(목적) / 条件(조건) / 让步(양보) / 转折(전환) / 顺序(순서) / 并列(병렬) / 假设(가정) / 比喻(비유) / 比较(비교) / 程度(정도) / 背景(배경)
  - **敬语·语体**：敬语(높임) / 非敬语(반말) / 正式(격식체) / 非正式(비격식체)
  - **其他**：存在(존재) / 所有(소유) / 强调(강조) / 听说·转述(인용)
  - **表态·情态**：尝试(시도) / 义务(의무) / 请求(요청) / 禁止(금지) / 认知(인지) / 授受(수여) / 名词型(명사형) / 主题(주제) / 限制(제한) / 包含(포함)
  - **时间**：时间(시간) / 期间(기간) / 选择(선택)

## 12. 校验规则

| 规则 | 行为 |
|---|---|
| **related 悬空校验** | `related` 中以 `ko[a-z0-9]{12}` 开头的内部引用须匹配某条目 `id`；匹配失败标记为 `待订正(dangling)`，**不阻断转换**，在产出报告中列出待订正清单。`ext:` 前缀的外部参照不参与此校验 |
| **id 唯一性** | 同批 `items` 中 `id` 不得重复；重复时报错并阻断 |
| **realizations 词类约束** | 每个 `realizations` 条目的词干类型须与本行 `connections.attachesTo` 词类一致；动词行不得含形容词词干（如 `(으)러` 只接动词，其 `realizations` 不得出现 예쁘러 这类不存在形式），否则报错并阻断 |
| **common_errors 自洽** | `wrong` 不得与 `right` 相同 |
| **必填完整性** | §2 必填字段缺失时报错并阻断 |
