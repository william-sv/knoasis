# 用户指南 / User Guide

> 本页为占位页，内容待补充。

Knoasis 的使用流程（计划章节）：

- **导入知识包**：从应用内「学科包管理」导入 `.knowledgeset`（= `meta.json` + `template.json` + `knowledge.db`）；数据落在本地 `$APPDATA/knowledge/`，不上传云端。
- **检索与筛选**：按 level / type / category / tag 多维筛选，点击标签联动列表。
- **详情阅读**：元数据条 + 讲解正文 + 接续活用 + 例句 + 易错点 + 近似语法 + 相关语法。
- **收藏与笔记**：本地持久化；旧版 localStorage 收藏/笔记可一键迁移。
- **下载学科包**：下载源尚未接入，目录即将上线。
