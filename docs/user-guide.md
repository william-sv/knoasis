# Knoasis 用户指南

> 适用平台：macOS 桌面端 · 版本：v0.1.0
> 本指南面向普通使用者，按步骤介绍 Knoasis 的安装、使用与数据管理。

---

## 1. Knoasis 是什么

Knoasis（中文名「诺西斯」）是一款 macOS 上**离线运行**的知识库阅读软件。它把不同的知识内容封装成一个个独立的「学科包」（例如韩语语法、英语语法），你按需把学科包装进软件里，就能以统一的界面浏览、搜索、收藏这些知识点。

所有数据都存在你自己的电脑上，不需要联网，也不会上传任何内容。

## 2. 安装与首次启动

1. 打开 Knoasis 应用。
2. **第一次启动时，软件会停在首页**，因为此时还没有任何学科包。

此时首页顶部会出现一块**空态引导**（标题为「还没有任何学科包」），并提供两个快捷入口：

- 「**导入学科包…**」：打开「学科包管理」弹窗导入本地学科包。
- 「**浏览可下载学科包**」：打开「学科包下载」窗口（演示功能，见第 4 节）。

引导卡下方是四张功能卡片：

| 卡片 | 作用 |
| --- | --- |
| 学科下载 | 浏览并下载全新的学科知识包（当前为演示功能，见第 4 节） |
| 学科管理 | 导入、删除或启用停用本地学科包 |
| 软件设置 | 外观主题、数据源状态与版本信息 |
| 用户指南 | 查看使用说明与常见问题文档（即本文档） |

> 📷 截图占位：首次启动的首页（空态引导 + 四张功能卡片）

**所以第一次使用的第一步，是先准备并导入一个学科包**（见第 4、5 节）。

> 提示：工具栏左上角的 Logo 可以随时「回到浏览」；Logo 右侧的首页图标可以回到首页。

---

## 3. 认识「学科包」

「学科包」是 Knoasis 装载知识的单位，本身就是一个文件夹（目录），后缀名为 `.knowledgeset`，例如：

```
kr-grammar.knowledgeset/
├── meta.json        # 学科的名称、版本、分类等描述信息
├── knowledge.db     # 学科的知识点数据
└── template.json    # 详情页的展示结构（可选）
```

一个学科包 = 一个学科。删除或停用某个学科包，不会影响其他学科，也不会影响你的收藏与笔记。

---

## 4. 学科包从哪里来

学科包可以通过以下方式获得：

- 由 **Knoasis Studio** 制作导出（一个配套的打包工具，把整理好的数据转成 `.knowledgeset`）。
- 由**他人分享**的 `.knowledgeset` 目录（例如从同事、朋友处拷贝，或从网络下载）。

> 注意：Knoasis 本身**不再内置**任何学科包。以前随软件附带的韩语、英语包已移除，因此首次打开必然是空的，需要你自行导入。
>
> 首页的「学科下载」目前是**演示功能**，点击「下载」会提示「演示数据：下载功能尚未接入」，请以第 4、5 节的导入方式为准。

## 5. 导入学科包

导入操作在「学科包管理」中完成（首页「学科管理」卡片，或工具栏菜单 →「管理学科包」）。

1. 点击「**导入学科包…**」。
2. 在弹出的目录选择框里，选中一个 `.knowledgeset` 目录。
3. 导入成功后，软件会提示「已导入「<学科名>」<条目数> 条」，并自动刷新，学科立即出现在列表中。

> 如果系统目录选择框打不开，界面会切换为手动输入模式，直接把学科包目录的**绝对路径**粘贴进去，再点「导入」即可。

导入后，学科包会被复制到本机的「学科包目录」（用户知识根，见第 14 节）。

> 📷 截图占位：学科包管理弹窗（导入学科包… / 刷新 / 学科包列表）

## 6. 启用、停用与删除学科包

在「学科包管理」弹窗中，每个学科包右侧都有对应操作：

| 操作 | 说明 |
| --- | --- |
| 启用 / 停用 | 点击行首的开关切换。**停用的学科包不参与浏览与搜索**，但会保留在管理面板，可随时重新启用。 |
| 删除 | 删除该学科包。点击后会先出现「确认删除」，确认后再执行。 |

- 「内置」学科包不能删除，删除操作会退化为「停用」。
- 删除或停用后，软件会自动重载，无需重启应用。
- 你的**收藏与笔记不会因为删除/停用学科包而丢失**。

弹窗底部显示「学科包目录」，点「打开目录」可以在系统文件管理器中打开该目录。

> 📷 截图占位：学科包管理弹窗中的启用/停用开关与删除按钮

## 7. 进入学科开始浏览

- 点工具栏左上角的 **Logo**（回到浏览）即可进入浏览界面，默认显示「全部学科」的知识点。
- 如果你只装了一个学科包，浏览界面就只会显示这个学科的内容。

**软件会记住你上次选择的学科包**。下次打开 Knoasis 时：

- 记住的是某个学科包、且它仍存在并处于启用状态 → **直接进入该学科的浏览页**。
- 记住的是「全部学科」→ 进入浏览页，显示全部学科。
- 记住的学科包**已被删除或停用** → 回到首页，并清除这条失效记忆。
- 从未选择过任何学科包 → 停在首页。

（选择学科包时，选择「全部学科」也会被记为一次有效选择。）

---

## 8. 浏览与搜索知识点

进入浏览界面后，界面分为左右两栏：

- **左栏：知识点列表**，按「分类」分组，组标题为灰色小字；列表上方显示「共 N 个知识点」。
- **右栏：知识点详情**。

**搜索**：使用工具栏中央的搜索框，输入「名称 / 别名 / 关键词」即可实时筛选。搜索范围为「全部学科 / 当前学科」的名称、别名与摘要。

- 搜索框右侧的 ✕ 可清除搜索；在搜索框中按 `Esc` 也会清除并退出输入。
- 搜索无结果时，右栏会出现「没有找到「关键词」」的提示，点「清除搜索」即可恢复。

底部状态栏右侧会显示当前范围（如「当前：全部学科」）与当前条数（「共 N 条」）；有筛选时显示「筛选 N 项」，搜索时显示命中数量与耗时。

> 📷 截图占位：左栏分组列表 + 顶部搜索框

## 9. 阅读知识点详情

在左栏点击任意知识点，右栏会显示它的详情。顶部依次是标题、别名与摘要；左上角是可点击的标签，右上角是收藏与复制两个按钮：

- **标签**（左上角）：学科、类型、等级、分类（可点击联动筛选，详见第 10 节）。
- **收藏星标**（右上角）：点一下「加入收藏」，再点一下「取消收藏」。
- **复制按钮**（右上角）：把当前知识点复制为 Markdown（或纯文本）。

正文按内容类型分区块展示，常见区块有：讲解段落、语法信息、释义、使用场景、例句（中韩/中英对照）、近似语法、图解等。**内容为空的区块会自动隐藏**，这是正常现象。

详情页底部还可以展开「笔记」，记录你自己的理解，输入即自动保存到本地。

> 📷 截图占位：知识点详情页（标签 / 标题 / 释义 / 例句 / 近似语法）

## 10. 用详情页标签联动筛选

详情页顶部的四个标签（学科 / 类型 / 等级 / 分类）都是**可点击的**，但行为分两类：

- **学科标签 = 切换学科**：点击后切换到该学科（左栏显示该学科的全部知识点）；如果当前已经在该学科，**再点一次则回到「全部学科」**。
- **类型 / 等级 / 分类标签 = 在当前学科范围内筛选**：点击后左栏只显示与该项相同的知识点。

两条通用规则：

- **再点一次同一个标签 = 取消**（开关式）；被选中的标签会高亮显示。
- 筛选与顶部搜索框的关键词是 **AND（同时满足）** 关系。

**在哪里看到当前筛选**：

- 左栏上方会回显生效条件，如「等级：TOPIK I」「类型：语法」「分类：时态」，并提供「**清除筛选**」按钮一键清空。
- 底部状态栏显示「筛选 N 项 · 共 M 条」。

若筛选后当前选中的知识点已不在结果里，右栏会回到「还没有选择知识点」的空态；只有搜索无结果时，才会保留上次详情并盖一层灰遮罩。

## 11. 收藏与收藏导出

**收藏**：在详情页点星标，或点击列表项的收藏标记。收藏是跨学科统一管理的——收藏过的知识点会集中出现在「收藏夹」里。

打开收藏夹：工具栏菜单（右上角）→「**收藏夹**」。面板中可点击任意条目跳转，也可点条目右侧的 ✕ 取消收藏。

**导出收藏**：工具栏菜单 →「**导出收藏夹**」，会下载一个 JSON 文件（`knoasis-userdata-<时间>.json`），其中包含你的收藏与笔记。

> 📷 截图占位：收藏夹面板与工具栏菜单（管理学科包 / 收藏夹 / 导出收藏夹）

## 12. 复制内容

**可以选中复制**：详情页正文（讲解段落、语法信息、释义、使用场景、例句、近似语法、图解等各区块）以及左栏列表里的知识点名称，都可以用鼠标**选中**，再按 `Cmd + C` 复制。

**不能选中复制**：按钮、工具栏、状态栏、列表上方的筛选条、左右分栏的分隔条、标签（chip），以及菜单 / 弹窗 / 提示（toast）等界面控件均不可选中，以避免误选。

**整条复制**：详情页右上角的复制按钮仍然可用，可把当前知识点一次性复制为 Markdown（或纯文本），粘贴到任意位置即可用。

> 📷 截图占位：选中详情正文后复制

## 13. 外观与设置

打开设置：首页「软件设置」卡片。（设置页左上角「返回」可回到浏览界面。）

设置页包含三部分：

**主题外观**：三选一

| 选项 | 说明 |
| --- | --- |
| 跟随系统 | 随系统深色 / 浅色外观自动切换 |
| 浅色 | 始终使用浅色外观 |
| 深色 | 始终使用深色外观 |

（也可以直接点工具栏右侧的太阳/月亮图标，快速在浅色与深色之间切换。）

**数据源**：显示当前已加载的「学科包」数量、「总条目数」，以及「知识根」目录位置（即第 14 节的学科包目录），点「打开目录」可在文件管理器中打开。

**关于**：显示应用版本 `Knoasis v0.1.0` 与「学科包 schema 支持版本 1」。

## 14. 数据存放在哪里：备份与迁移

Knoasis 将数据分两部分存在本机：

- **学科包**（可随时重新导入）：
  `~/Library/Application Support/com.william.knoasis/knowledge/`
- **你的收藏与笔记**（不可再生，注意备份）：
  `~/Library/Application Support/com.william.knoasis/userdata.db`

**备份**：拷贝上面的 `knowledge/` 目录与 `userdata.db` 文件即可。
**迁移**：在新电脑上安装 Knoasis 后，把这两项放回相同位置即可恢复。

> 说明：替换或删除学科包不会清空收藏与笔记。若某条收藏对应的知识点已不在当前学科包里，点击时会提示「条目已不在当前数据中」。

## 15. 常见问题

**Q：第一次打开 Knoasis，为什么是空的？**
Knoasis 不再内置任何学科包，首次启动时没有任何内容属于正常现象。按首页「还没有任何学科包」的引导，点「导入学科包…」导入一个学科包即可开始浏览（见第 4、5 节）。

**Q：上次明明选过学科，为什么这次又回到首页了？**
软件会记住你上次选择的学科包。如果记住的那个学科包之后被**删除或停用**，这条记忆会失效，重新打开时会回到首页并清除该记忆。导入或重新启用该学科包后，下次即可正常进入。

**Q：导入后看不到学科包？**
确认你导入的是 `.knowledgeset` **目录**（不是压缩包或单个文件），且目录内包含 `meta.json` 和 `knowledge.db`。导入成功后可在「学科包管理」里看到它；若是「已停用」状态，点开关启用即可。

**Q：我明明（用 Studio）导出了学科包，部署后却看不到？**
学科包必须放到用户知识根目录：
`~/Library/Application Support/com.william.knoasis/knowledge/`
放好后，在「学科包管理」里点「刷新」（或重启应用）即可被发现。
若包的 schema 版本高于本应用支持的版本，会被跳过；请更新应用或使用兼容版本。

**Q：搜索不到某个学科的知识点？**
该学科包可能处于「停用」状态。停用的学科包不参与浏览与搜索，到「学科包管理」重新启用即可。

**Q：如何卸载 Knoasis？**
退出应用后，把应用本体拖入废纸篓。若要彻底清除数据，再删除数据目录：
`~/Library/Application Support/com.william.knoasis/`
（删除前建议先备份 `userdata.db`，以免丢失收藏与笔记。）

**Q：如何反馈问题？**
请记录：macOS 版本、软件版本、操作步骤与现象（最好附截图），以及涉及的学科包名称，反馈给维护者。
